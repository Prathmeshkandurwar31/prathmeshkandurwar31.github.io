# Prathmesh Kandurwar — Portfolio Website

A responsive, recruiter-friendly portfolio website for software engineering, AI/ML, data science, analytics and data engineering roles.

## Files
- `index.html` — complete portfolio website (HTML, CSS and JavaScript)
- `assets/PRATHMESH KANDURWAR pic.jpg` — profile photo
- `assets/resume-Prathmesh_kandurwar_RESUME(1c)` — the latest data-engineering-focused resume available from your files

## Preview locally
Open `index.html` in a browser. For a local development server, run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Create a repository named `prathmeshkandurwar31.github.io` (Public).
2. Upload `index.html` and the complete `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for the deployment and open `https://prathmeshkandurwar31.github.io`.
